# ПРОЕКТ-ГЕНЕЗИС

Мрачный подводный атомный техно-триллер с элементами боди-хоррора.
Интерактивный комикс-читалка на **Konva.js**: вся графика собрана из геометрических
примитивов прямо в коде, диалоги живут в HTML/CSS поверх Canvas.

> **10 томов × 20 страниц = 200 страниц.** Все тома написаны и отрисованы.
> Сценарий каждого тома — отдельный файл в `scenario/`.

---

## Быстрый старт

Никакой сборки не нужно: сайт статический.

```bash
python3 -m http.server 8080
# открыть http://localhost:8080
```

`index.html` — титульный экран и сцена. Кнопка «Открыть том 01» переносит в читалку,
дальше том выбирается в содержании (`I`) или стрелками в HUD.

## Управление

| Действие | Что делает |
|---|---|
| колесо мыши | зум к курсору |
| перетаскивание (ЛКМ) | панорама, с инерцией |
| двойной клик / `FIT` | вписать страницу |
| `←` `→` `Space` `PgUp/PgDn` | страницы |
| `+` / `−` / `0` | зум / сброс |
| `I` | содержание (тома и страницы) |
| `H` | скрыть интерфейс |
| клик по мини-карте | перейти в точку страницы |

На тач-устройствах работают те же жесты (pointer events), стрелки по краям скрыты,
страницы переключаются кнопками дока.

## Как записывается страница

Страница — компактный объект: локация, палитра, камера, персонажи, реквизит и тексты.
Текст указывает не координаты, а **слот** (`PG.SLOTS`) и, при желании, индекс
говорящего в `cast` — «хвост» реплики сам встанет ему к голове.

```js
{
  set: 'medbay', tone: 'teal', cam: { x: 600, y: 900, z: 0.98 },
  setOpts: { seed: 601, beds: [330, 900] },
  cast: [C('mnema', 700, 1350, 1.05, { rim: '#d9c8ff', threads: true })],
  prop: [P('chair', 320, 1420, 1)],
  text: [
    N('TL1', 'В «Ярусе-3» не справляли дней рождения.'),
    S('TR1', 'МНЕМА', 'Сядьте. Скажите имя.', 0),
    N('BL2', 'Она знала лучше.')
  ]
}
```

Шорткаты: `C()` персонаж, `P()` реквизит, `L()` свет, `N()` мизансцена,
`S()` реплика, `R()` радио, `Y()` системное сообщение, `M()` реплика за стеклом.

`PG.compilePage` разворачивает слоты в `x, y, w, size`, считает точку «хвоста»
по голове говорящего и кадрирует сцену (`PG.framePage`), чтобы фигуры читались
на странице 1200 × 1800.

## Как устроена графика

* Только `Konva.Rect`, `Konva.Line`, `Konva.Circle`, `Konva.Ellipse`,
  `Konva.Path`, `Konva.Arc` и `Konva.Text` (служебные трафареты на металле).
* Ни одного `png/jpg/webp/svg`, ни одного внешнего ассета.
* Каждая сцена — детерминированная функция: при повторном открытии страница
  выглядит идентично (свой seed у каждой страницы).
* Слои: `scene` (фон + персонажи) → `overlay` (плашка места и номера) →
  HTML-слой текста.

## Как синхронизирован текст

`compilePage` хранит для каждого блока координаты `x, y, w` и кегль в системе
страницы 1200 × 1800. Konva-сцена масштабируется через `stage.scale()`,
а HTML-слой получает тот же трансформ:

```js
textLayer.style.transform =
  `translate(${stage.x()}px, ${stage.y()}px) scale(${stage.scaleX()})`;
```

Поэтому текст остаётся векторно-чётким на любом зуме, а плашки и «хвосты»
реплик (линия + пульсирующий маркер у говорящего) попадают точно в персонажей.

## Сценарий

Единый источник текста — `js/volumes.js` и `js/volumes2.js`. Из них
генерируются все файлы `scenario/`:

```bash
node tools/export-scenario.cjs
```

Формат — страницы, мизансцены и реплики, без разбивки на панели.

## Проверка

```bash
node tools/export-scenario.cjs     # валидность данных + 10 документов
node tools/check-layout.cjs        # компоновка всех 200 страниц
```

Движок протестирован прогоном в DOM-песочнице: инициализация, переключение
всех 10 томов, переходы по всем 200 страницам, зум колесом, `FIT`, кнопки
дока, содержание — без ошибок консоли.
