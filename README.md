# Vale

**Vale** — экспериментальный мессенджер для Android и Windows. Визуальный стиль: спокойный минимализм, тёплый светлый интерфейс и приглушённый хвойный акцент; на телефоне используется нижняя навигация, на ПК — боковая панель.

> **Не используйте Vale для чувствительной информации.** Протокол и реализация не проходили независимый аудит. Это не готовый защищённый мессенджер и не обеспечивает анонимность. Ниже перечислены реальные возможности и ограничения; неподдерживаемые функции не имитируются.

## Что работает в этом прототипе

- Локальная регистрация без телефона и email: libsodium создаёт пару Ed25519; публичный ключ — ID. Контакты добавляются по ID или QR-коду, есть сканирование камерой Android и веб-камерой Windows.
- Текстовые сообщения передаются **напрямую по локальной IPv4-сети**, пока приложения запущены. Подпись Ed25519, XChaCha20-Poly1305 и ключ, полученный из преобразованных в X25519 ключей и HMAC-SHA-256. Заголовок аутентифицируется, подпись проверяется до расшифровки; повторы отсекаются. Сообщения, которые не удалось передать, остаются в локальной очереди.
- Можно добровольно включить ограниченную ретрансляцию по локальной сети: промежуточное устройство должно добавить **и отправителя, и получателя** в контакты; максимальная глубина — 3 перехода. Это не Bluetooth/Nearby mesh и не надёжная система доставки при выключенных устройствах.
- Таймер удаления новых сообщений: 1 минута, 1 час, 24 часа или 7 дней. Эмодзи можно вставлять в сообщения.
- Зашифрованное локальное хранилище: на Android — SQLCipher, ключ защищён Android Keystore; на Windows — SQLite3MultipleCiphers в совместимом режиме SQLCipher 4, ключ защищён DPAPI текущего пользователя. Android backup выключен.
- Скрытие чатов: тройное нажатие логотипа (или Ctrl+Shift+X на Windows) показывает калькулятор и очищает кэш приложения. На Android также меняется иконка лаунчера. Для возврата трижды нажмите «=».

## Ограничения безопасности

- Собеседники должны добавить ключи **друг друга** и проверить их по доверенному каналу. QR/ID сам по себе не подтверждает личность. При ошибке в ID возможна подмена контакта.
- Это нестандартный протокол на статических ключах: **нет forward secrecy и post-compromise security**. Компрометация ключа может раскрыть записанный ранее трафик. Нет независимой проверки протокола или аудита криптографии.
- Локальная сеть, ретрансляторы и наблюдатели видят IP, ID отправителя и получателя, время и размер сообщений. Tor/VPN и скрытие IP **отсутствуют**. Разрешены только локальные IPv4-адреса, DNS-имена и публичные адреса не используются.
- Исчезновение сообщения — программное удаление после истечения срока, пока приложение запущено. Это не гарантирует уничтожение копий, скриншотов, данных на втором устройстве, резервных копий, страниц SQLite или носителя; точность зависит от часов устройств.
- Режим калькулятора **не является блокировкой паролем**, не уничтожает базу или ключи, не гарантирует очистку RAM и может оставлять системные следы. На Windows иконка приложения не меняется. Android может обновить значок не мгновенно.
- Нет фонового сервиса: при закрытом/усыплённом приложении приём и очистка по таймеру могут задерживаться. Нет подтверждения прочтения; статус «передано» означает только приём работающим приложением получателя.
- **Не реализованы:** Bluetooth / Wi-Fi Direct / Google Nearby Connections, Tor/VPN, WebRTC-звонки, голосовые сообщения, видео-кружки, передача файлов и пользовательские стикеры. Версии для iOS, macOS и Linux не собраны. Не называйте эту версию абсолютно приватной или production-ready.
- APK — отладочная сборка, подписанная стандартным временным debug-ключом CI; EXE не подписан сертификатом издателя. Для распространения нужны собственное управление ключами подписи и дополнительное тестирование.

## Как попробовать

1. Установите APK на Android 8+ либо EXE на Windows x64; для Windows может понадобиться разрешить входящие подключения в брандмауэре.
2. Подключите оба устройства к одной локальной сети и откройте Vale на обоих. Создайте профили.
3. На вкладке «Профиль» покажите QR-код. На втором устройстве выберите «Контакты → + → Сканировать QR-код» или вставьте скопированный публичный ID. Повторите в обратном направлении: **оба** пользователя должны добавить друг друга.
4. Если IP не попал в QR-код, укажите локальный IPv4-адрес второго устройства вручную. Адрес и порт показаны в профиле. При наличии нескольких интерфейсов выбранный адрес может быть не тем, который нужен; исправьте его в контакте вручную.
5. Откройте чат и отправьте сообщение. «В очереди» означает, что приложение ещё не получило подтверждение; для доставки оба приложения должны быть открыты.

## Структура

```text
app/src/commonMain/        Compose Multiplatform UI, состояние и контракты
app/src/jvmSharedMain/     криптография, протокол, TCP, общая логика Android/JVM
app/src/androidMain/       Activity, Keystore, SQLCipher, камера и значки
app/src/desktopMain/       окно Windows, DPAPI, SQLCipher-совместимый SQLite, веб-камера
app/src/desktopTest/       тесты криптографии, транспорта, двух клиентов и хранилища
.github/workflows/build.yml  матрица Android APK + Windows EXE
```

## Сборка

Требуются JDK 17 для Android и JDK 21 для Windows, Android SDK 35 и сетевой доступ к Gradle/Maven. На Windows для упаковки EXE также нужен WiX 3.x в `PATH`.

```bash
./gradlew :app:assembleDebug        # Android debug APK
./gradlew :app:desktopTest          # тесты на Windows
./gradlew :app:packageExe           # установщик Windows, запускать на Windows
```

GitHub Actions собирает обе цели матрицей, проверяет упакованный Windows runtime и запуск Android в эмуляторе, и публикует отдельные ZIP-артефакты на странице конкретного запуска на 30 дней. Репозиторий приватный, поэтому скачивание требует доступа к нему. Артефакты и SDK не хранятся в git.
