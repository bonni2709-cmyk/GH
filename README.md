# Vale

**Vale** — экспериментальный децентрализованный мессенджер для Android и Windows. Тёплый минималистичный интерфейс адаптируется к устройству: нижняя навигация на телефоне и боковая панель на ПК. Для регистрации не нужны телефон или учётная запись; центрального сервера Vale нет.

> **Не используйте Vale для чувствительной информации.** Протокол, транспорт и реализация не прошли независимый аудит; абсолютная приватность и надёжная доставка не гарантируются. Ниже описаны реальные возможности и ограничения.

## Возможности

- **Личность и контакты.** Локально генерируется пара Ed25519; публичный ключ служит ID. Контакты добавляются по ID или QR, который также может содержать адрес IPv4 либо onion. На Android и Windows есть сканирование камерой.
- **Зашифрованные сообщения.** Ed25519-подпись, XChaCha20-Poly1305 и ключ из Ed25519→X25519 и HMAC-SHA-256. Подписи и ограничения проверяются до расшифровки/ретрансляции, повторы отсекаются; сообщения без маршрута остаются в очереди. Это собственный протокол на статических ключах **без forward secrecy**.
- **Сеть и mesh.** Локальная сеть IPv4 на Android и Windows; на Android дополнительно можно включить Nearby Connections (Bluetooth/BLE и Wi‑Fi, выбор радио делает Google Play services). Ретрансляция включается отдельно: промежуточный узел должен знать обоих участников; ограничение — три перехода. На Windows Nearby/Bluetooth/Wi-Fi Direct не реализованы. Очередь хранится локально; выключенные устройства не пересылают сообщения.
- **Tor.** Выключен по умолчанию. При включении Vale поднимает собственный onion v3 service, принимает соединения только через loopback и отправляет только на onion через локальный SOCKS5 без DNS/fallback на LAN. Nearby и прямые WebRTC-звонки в этом режиме отключаются. Обменяйтесь новыми onion-адресами через QR или карточки контактов. Нужен работающий доступ к сети Tor; bridges/VPN не настроены.
- **Медиа.** Голосовые Opus и видеокружки H.264 записываются в локальной странице системного браузера, проверяются и передаются внутри зашифрованного пакета. Есть эмодзи-стикеры и пользовательские PNG/WebP/JPEG. Лимит 768 КБ, до 60 секунд аудио или 15 секунд видео; поддержка кодеков зависит от браузера и устройства, в частности H.264 может отсутствовать. Вложения хранятся в зашифрованной базе.
- **Звонки.** Голосовые и видеозвонки — WebRTC в браузере, SDP-сигнализация передаётся как зашифрованное сообщение Vale. STUN/TURN нет: соединение только прямое и может не пройти через NAT. Собеседнику и сети видны адреса; Tor для медиа звонка не используется. При включённом Tor звонки блокируются; если звонок открыт, сначала завершите его и дождитесь закрытия соединения в браузере, а затем включите Tor.
- **Эфемерные сообщения и хранение.** Таймер 1 минута, 1 час, 24 часа или 7 дней. На Android база SQLCipher, ключ защищён Keystore; на Windows SQLite3MultipleCiphers в режиме SQLCipher 4, ключ защищён DPAPI текущего пользователя. Android backup выключен.
- **SOS-маскировка.** Тройное нажатие логотипа (или Ctrl+Shift+X на Windows) скрывает чаты, останавливает сетевые компоненты и открывает калькулятор; на Android меняется значок лаунчера. Возврат — три нажатия «=». Открытую вкладку звонка закройте вручную: приложение не управляет внешним браузером напрямую. Это маскировка, не блокировка и не уничтожение данных.

## Важные ограничения

- Оба собеседника должны добавить ключи **друг друга** и проверить их по доверенному каналу: QR сам по себе не подтверждает личность. Ретранслятор тоже должен добавить обоих.
- Нет независимого аудита, forward secrecy и post-compromise security. Компрометация долгосрочного ключа может раскрыть записанные ранее пакеты. IP, ID, время и размеры видны в локальной сети; ретрансляторы видят заголовки, но не содержимое. Tor уменьшает раскрытие адреса, но не гарантирует анонимность; провайдер может видеть использование Tor. Один и тот же публичный ID используется в разных режимах и позволяет связать их между собой.
- Onion-ключ Tor хранится в файлах приватного каталога приложения/учётной записи, **не в SQLCipher**. Доступ к разблокированному устройству, вредоносное ПО и компрометация ОС могут раскрыть данные; локальные процессы и браузер являются частью доверенной среды.
- Радиососеди обнаруживаются и подключаются автоматически; проверить личность нужно по ключу контакта. Nearby требует Google Play services, включённых радио и разрешений соответствующей версии Android. Работа и дальность зависят от устройства; обмен на физических устройствах ещё требует проверки.
- Статус «передано» появляется после подписи квитанции ключом конечного получателя и сохранения сообщения в его базе. Это не отметка прочтения, не защита от скомпрометированного получателя и не гарантия, что сообщение сохранится навсегда.
- Исчезновение сообщения — программное удаление при работающем приложении, не безопасное стирание копий, скриншотов, страниц базы или носителя. Зависит от часов. SOS не защищён паролем и не очищает RAM гарантированно.
- Фонового сервиса доставки нет. Для обмена приложения и промежуточные узлы должны работать; при энергосбережении Android соединения могут останавливаться. Очередь и задержки при передаче медиа ограничены ресурсами устройства.
- APK — debug-сборка с временной подписью CI, EXE не подписан сертификатом издателя. Для полноценного распространения нужны собственные ключи подписи, аудит и полное тестирование. iOS, macOS и Linux в этом проекте не поставляются.

## Как попробовать

1. Установите APK на Android 8+ или EXE на Windows x64 и откройте приложение на обоих устройствах. Ранние прототипы используют другую квитанцию транспорта: обновите оба устройства до одной версии. Разрешите локальные соединения в брандмауэре Windows при необходимости.
2. Создайте профили. Каждый пользователь добавляет второго через «Контакты → + → Сканировать QR-код» или вручную; сверьте публичные ключи. На вкладке «Профиль» находится ваш QR.
3. Для LAN укажите локальный IPv4 каждого устройства, если он не попал в QR; при нескольких интерфейсах автоматически выбранный адрес может быть неверным. На Android можно вместо этого включить «Связь поблизости» в настройках и предоставить разрешения. Для Tor включите «Только через Tor» на обоих устройствах, дождитесь появления onion-адресов и заново передайте их контактам.
4. Для мультихопа включите «Передавать сообщения через меня» на промежуточном устройстве и добавьте туда обоих участников. Оставьте все устройства включёнными и приложения открытыми.
5. В чате отправляйте текст и стикеры; кнопка вложения открывает локальную браузерную студию для записи и выбора изображения. Звонок также откроется в браузере, где нужно разрешить микрофон/камеру.

## Структура

```text
app/src/commonMain/        Compose UI, состояние и платформенные контракты
app/src/jvmSharedMain/     криптография, протокол, TCP/SOCKS, локальный медиа-мост
app/src/androidMain/       Android Activity, Nearby, Tor, Keystore, SQLCipher и камера
app/src/desktopMain/       Windows окно, Tor, DPAPI, SQLCipher-совместимый SQLite и камера
app/src/desktopTest/       тесты протокола, клиентов, медиа, mesh и маршрутизации Tor
.github/workflows/build.yml  матрица Android APK + Windows EXE и smoke-тесты
```

## Сборка

Нужны JDK 17 для Android и JDK 21 для Windows, Android SDK 35 и сетевой доступ к Gradle/Maven; для EXE также WiX 3.x. Android Tor 0.4.9.14 извлекается автоматически из закреплённого AAR с проверкой SHA-256; исходники TorService соответствующей версии собраны под JDK 17. Лицензии находятся в Android assets и `app/packaging/common/`.

```bash
./gradlew :app:assembleDebug        # Android debug APK
./gradlew :app:desktopTest          # тесты на Windows
./gradlew :app:packageExe           # установщик Windows, запускать на Windows
```

Для Windows Tor Expert Bundle 15.0.25 нужно извлечь в `app/packaging/windows/tor-bundle/`; workflow скачивает архив из Tor Project и проверяет закреплённый SHA-256. Локально путь к `tor.exe` также можно указать через `VALE_TOR_EXECUTABLE` для запуска без упаковки. Не запускайте непроверенный бинарник.

GitHub Actions собирает две цели матрицей, запускает desktop-тесты, проверяет Windows runtime, локальную медиастраницу с поддельными устройствами и сигнализацией, а также Android в эмуляторе, а затем публикует два ZIP-артефакта на 30 дней. Скачивание из приватного репозитория требует доступа. Бинарные сборки и SDK не хранятся в git.
